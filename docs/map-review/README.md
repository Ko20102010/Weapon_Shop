This directory contains the current visual review and the next-pass art improvement plan for the Weapon Shop world.

## Files

- [ROOM_BY_ROOM_VISUAL_CRITIQUE.md](./ROOM_BY_ROOM_VISUAL_CRITIQUE.md) — full critique of the current visual style room by room
- [ART_IMPROVEMENT_PLAN_2_WEEKS.md](./ART_IMPROVEMENT_PLAN_2_WEEKS.md) — concrete 2-week art pass plan
- [SPRITE_ASSET_CHECKLIST.md](./SPRITE_ASSET_CHECKLIST.md) — sprite and asset checklist for Forge, Alchemy, Retail, and Customer Hall
- [MOBILE_ART_QA_CHECKLIST.md](./MOBILE_ART_QA_CHECKLIST.md) — iPhone Safari mobile-first art QA checklist

## Source notes

- The artwork pass is intended to preserve the route matrix and collision model.
- The visual goal is a readable, mobile-first woodland workshop aesthetic with strong room identity and low decorative overhead.
- All visual work should be validated on-device before claiming a mobile-ready build.
